# 👋 Holberton School — ChatGPT Introduction

Welcome to the **holbertonschool-chatgpt-introduction** repository, a collection of exercises completed as part of the Holberton School curriculum, using ChatGPT to correct, improve, and document classic Python scripts.

This repository contains several interactive Python programs covering fundamental concepts such as:
- loops and recursion,
- basic data structures,
- user input validation,
- and game logic.

## 📌 Project Description

This repository collects various Python exercises developed with the help of ChatGPT. Each script demonstrates:
- clear and educational logic,
- robust error handling,
- and interactive terminal-based user interfaces.

The exercises cover:
- classic algorithms (factorial),
- simple terminal games (Tic-Tac-Toe, Minesweeper),
- and utility applications (account management).

---

## 📁 Repository Contents

| File | Description |
|------|-------------|
| `factorial_recursive.py` | Calculates the factorial of a number using recursion |
